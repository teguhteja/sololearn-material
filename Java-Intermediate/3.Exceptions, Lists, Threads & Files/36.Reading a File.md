# 36. Reading a File

### Reading a File
Files are useful for storing and retrieving data, and there are several ways to read from a file. One of the simplest methods is to use the **`Scanner`** class from the `java.util` package.

The constructor of the **`Scanner`** class can take a `File` object as input.

To read the contents of a text file at the path `"C:\\sololearn\\test.txt"`, you need to create a `File` object with the corresponding path and pass it to the `Scanner` object.

```java
try {
    File x = new File("C:\\sololearn\\test.txt");
    Scanner sc = new Scanner(x);      
} catch (FileNotFoundException e) {
    System.out.println("File not found");
}
```

We surround the code with a `try/catch` block because there's a chance that the file may not exist.

### Question: Which class can be used for reading files?
- **Answer**: Scanner

### Reading a File
The **`Scanner`** class inherits from the **`Iterator`** class, so it behaves like one. We can use the `Scanner` object's **`next()`** method to read the file's contents.

```java
try {
    File x = new File("C:\\sololearn\\test.txt");
    Scanner sc = new Scanner(x);
    while (sc.hasNext()) {
        System.out.println(sc.next());
    }
    sc.close();
} catch (FileNotFoundException e) {
    System.out.println("Error");
}
```

In the example above, the file's contents are output word by word because the **`next()`** method returns each word separately.

It's always good practice to close the file when finished working with it. You can do this using the `Scanner`'s **`close()`** method.

### Fill in the blanks to read and print the content of the file `a.txt` and then close it:

```java
try {
    File f = new File("a.txt");
    Scanner sc = new Scanner(f);
    while (sc.hasNext()) {
        String a = sc.next();
        String b = sc.next();
        System.out.println(a + " " + b);
    }
    sc.close();
} catch (Exception e) {
    System.out.println("Error");
}
```

In this code:
- A `File` object is created for `"a.txt"`.
- The `Scanner` reads from the file and prints pairs of words from the file.
- The file is then closed.
