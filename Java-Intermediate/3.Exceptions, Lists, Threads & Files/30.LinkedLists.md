# 30. LinkedLists

### LinkedList Overview

The `LinkedList` is very similar in syntax to the `ArrayList`. You can easily switch between them by changing the object type.

```java
import java.util.LinkedList;

public class MyClass {
    public static void main(String[] args) {
        LinkedList<String> c = new LinkedList<String>();
        c.add("Red");
        c.add("Blue");
        c.add("Green");
        c.add("Orange");
        c.remove("Green");
        System.out.println(c);
    }
}
```

Unlike `ArrayList`, you **cannot specify an initial capacity** for the `LinkedList`.

### Creating a LinkedList and Adding Elements

```java
LinkedList<String> list = new LinkedList<String>();
list.add("Hey");
System.out.println(list.get(0));
```

### LinkedList vs. ArrayList

The most notable difference between `LinkedList` and `ArrayList` lies in how they store objects:

- **ArrayList**: Better for storing and accessing data, as it is very similar to a normal array.
- **LinkedList**: Better for manipulating data, such as making numerous inserts and deletes.

In addition to storing the object, the `LinkedList` stores the memory address (or link) of the element that follows it. It is called a `LinkedList` because each element contains a link to the next element.

### Example: Iterating Over a LinkedList Using Enhanced For Loop

You can use the enhanced for loop to iterate over a `LinkedList`:

```java
import java.util.LinkedList;

public class MyClass {
    public static void main(String[] args) {
        LinkedList<String> c = new LinkedList<String>();
        c.add("Red");
        c.add("Blue");
        c.add("Green");
        c.add("Orange");
        c.remove("Green");
        
        for (String s: c) {
            System.out.println(s);
        }
    }
}
```

### Problem Solution: Filter Words Based on Length in LinkedList

Here’s a solution where the program takes input words, adds them to a `LinkedList`, and then outputs the words whose length is more than 4 characters:

```java
import java.util.LinkedList;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // Declare LinkedList to store words
        LinkedList<String> words = new LinkedList<String>();
        
        // Take input until LinkedList size is equal to 5
        while (words.size() < 5) {
            String word = scanner.nextLine();
            words.add(word);  // Add the word to LinkedList
        }
        
        // Output words whose length is greater than 4 characters
        for (String word : words) {
            if (word.length() > 4) {
                System.out.println(word);
            }
        }
    }
}
```

### Explanation:

1. We initialize a `Scanner` to take input from the user.
2. A `LinkedList<String>` named `words` is created to store the input words.
3. Inside the `while` loop, we keep adding words to the `LinkedList` until its size becomes 5.
4. After filling the `LinkedList`, we iterate over the list and print only those words whose length is greater than 4 characters.
