# 37. Creating & Writing Files

## Creating Files
The `Formatter` class from the `java.util` package is useful for creating content and writing it to files.

### Example:
```java
import java.util.Formatter;

public class MyClass {
   public static void main(String[] args) {
      try {
         Formatter f = new Formatter("C:\\sololearn\\test.txt");
      } catch (Exception e) {
         System.out.println("Error");
      }
   }
}
```

This code creates an empty file at the specified path. If the file already exists, it will be overwritten. A try/catch block is used to handle potential errors during file creation.

### Question:
Which class is used to write content to files?

**Answer:** `Formatter`

## Writing to Files
Once the file is created, you can write content to it using the same `Formatter` object's `format()` method.

### Example:
```java
import java.io.File;
import java.util.Scanner;
import java.util.Formatter;

public class MyClass {
    public static void main(String[] args) {
        try {
            Formatter f = new Formatter("test.txt");
            f.format("%s %s %s", "1", "John", "Smith \r\n");
            f.format("%s %s %s", "2", "Amy", "Brown");
            f.close();

            File x = new File("test.txt");
            Scanner sc = new Scanner(x);
            while(sc.hasNext()) {
                System.out.println(sc.next());
            }
            sc.close();
        } catch (Exception e) {
            System.out.println("Error");
        }
    }
}
```

The `format()` method formats its parameters according to its first argument, where:
- `%s` denotes a string and gets replaced by each subsequent parameter.
- The `\r\n` is used to create a newline in Windows.

The file created by this code contains:
```
1 John Smith
2 Amy Brown
```

### Note:
Always close the file after writing by calling `close()` on the `Formatter`.

## Example: Creating & Writing Files for a To-Do List
The following code allows you to input 3 tasks, write them to a file `tasks.txt`, and then read and print the tasks.

### Complete Solution:
```java
import java.io.File;
import java.util.Scanner;
import java.util.Formatter;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        try {
            Formatter f = new Formatter("tasks.txt"); // Create the file
            
            int count = 0;
            while (count < 3) {
                String task = input.nextLine(); // Take task as input
                f.format("%s\n", task); // Write the task to the file with a new line
                count++;
            }
            
            f.close(); // Close the file after writing
        } catch (Exception e) {
            System.out.println("Error");
        }
        
        readFile(); // Call the method to read and output the file content
    }

    // Method to read the file and output its contents
    public static void readFile() {
        try {
            File x = new File("tasks.txt");
            Scanner sc = new Scanner(x);
            while (sc.hasNextLine()) { // Read each line of the file
                System.out.println(sc.nextLine()); // Output the task
            }
            sc.close();
        } catch (Exception e) {
            System.out.println("Error");
        }
    }
}
```

### Explanation:
1. **Input Loop**: The program takes 3 tasks from the user using `input.nextLine()` and writes each task to the file `tasks.txt`.
2. **Writing to the File**: Each task is written to the file using `f.format("%s\n", task);`, ensuring each task appears on a new line.
3. **File Closing**: The `f.close()` method closes the file to prevent any issues after writing.
4. **Reading the File**: The `readFile()` method reads each task from the file and prints it.

### Sample Input:
```
Workout
Report
Pool
```

### Sample Output:
```
Workout
Report
Pool
```
