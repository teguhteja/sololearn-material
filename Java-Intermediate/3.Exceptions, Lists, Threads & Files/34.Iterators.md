# 34. Iterators

### Iterators
An Iterator is an object that enables cycling through a collection and obtaining or removing elements. 

Before accessing a collection through an iterator, you must obtain one. Each collection class provides an `iterator()` method that returns an iterator pointing to the start of the collection. By using this iterator object, you can access each element in the collection, one at a time.

The `Iterator` class provides the following methods:
- **`hasNext()`**: Returns `true` if there is at least one more element; otherwise, returns `false`.
- **`next()`**: Returns the next object and advances the iterator.
- **`remove()`**: Removes the last object returned by `next()` from the collection.

The `Iterator` class must be imported from the `java.util` package.

### Example:

```java
import java.util.Iterator;
import java.util.LinkedList;

public class MyClass {
    public static void main(String[] args) {
        LinkedList<String> animals = new LinkedList<String>();
        animals.add("fox");
        animals.add("cat");
        animals.add("dog");
        animals.add("rabbit");
        
        Iterator<String> it = animals.iterator();
        String value = it.next();
        System.out.println(value);
    }
}
```

### Output:
```
fox
```

### Iterators in Loops
Typically, iterators are used in loops. At each iteration of the loop, you can access the corresponding list element.

### Example:

```java
import java.util.Iterator;
import java.util.LinkedList;

public class MyClass {
    public static void main(String[] args) {
        LinkedList<String> animals = new LinkedList<String>();
        animals.add("fox");
        animals.add("cat");
        animals.add("dog");
        animals.add("rabbit");
        
        Iterator<String> it = animals.iterator();
        while(it.hasNext()) {
            String value = it.next();
            System.out.println(value);   
        }
    }
}
```

### Output:
```
fox
cat
dog
rabbit
```

### Example: Sum Calculation Using Iterator

Here’s the completed program using an `Iterator` to calculate and output the sum of elements in a `LinkedList`:

```java
import java.util.Scanner;
import java.util.Iterator;
import java.util.LinkedList;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        LinkedList<Integer> nums = new LinkedList<Integer>();
        
        // Taking 5 numbers as input
        while(nums.size() < 5) {
            int num = scanner.nextInt();
            nums.add(num);
        }
        
        int sum = 0;
        
        // Create an iterator for the LinkedList
        Iterator<Integer> iterator = nums.iterator();
        
        // Iterate through the LinkedList and calculate the sum
        while(iterator.hasNext()) {
            sum += iterator.next();
        }
        
        // Output the sum
        System.out.println(sum);
    }
}
```

### Explanation:
1. **LinkedList Initialization**: A `LinkedList<Integer>` is created to store integers.
2. **Input Loop**: The program reads 5 integers from the user and adds them to the `LinkedList`.
3. **Iterator**: An `Iterator` is used to traverse the `LinkedList` and sum the elements.
4. **Sum Calculation**: The iterator's `next()` method retrieves each element, and the sum is accumulated.
5. **Output**: The final sum is printed.

### Sample Input:
```
4
3
50
3
8
```

### Sample Output:
```
68
```
