# HashMap

Arrays and Lists store elements as ordered collections, with each element given an integer index.

`HashMap` is used for storing data collections as key-value pairs. One object is used as a key (index) to another object (the value). 

The `put`, `remove`, and `get` methods are used to add, delete, and access values in the `HashMap`.

### Example:

```java
import java.util.HashMap;

public class MyClass {
    public static void main(String[] args) {
        HashMap<String, Integer> points = new HashMap<String, Integer>();
        points.put("Amy", 154);
        points.put("Dave", 42);
        points.put("Rob", 733);
        System.out.println(points.get("Dave")); 
    }
}
```

We have created a `HashMap` with `String` as its keys and `Integer` as its values.

Use the `get` method with the corresponding key to access the `HashMap` elements.

### HashMap Key Features:

- A `HashMap` cannot contain duplicate keys. Adding a new item with a key that already exists will overwrite the old element.
- The `HashMap` class provides `containsKey` and `containsValue` methods to check for the presence of a specified key or value.
- If you try to get a value that is not present in the map, it returns `null`, which represents the absence of a value.

### Example: Remove Employees Younger Than a Given Age

To solve this problem, you need to iterate through the `nameArr` array, check the age of each employee using the `get()` method, and if the employee's age is less than the given age limit, remove that employee using the `remove()` method from the `HashMap`.

Here’s the updated code:

```java
import java.util.HashMap;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        
        Scanner scanner = new Scanner(System.in);
        
        HashMap<String, Integer> ages = new HashMap<String, Integer>();
        ages.put("David", 22);
        ages.put("Tom", 23);
        ages.put("Robert", 32);
        ages.put("Alice", 21);
        ages.put("Sophie", 19);
        ages.put("Maria", 24);
        ages.put("John", 28);
        
        String[] nameArr = new String[ages.size()];
        nameArr = ages.keySet().toArray(nameArr);
        
        int ageLimit = scanner.nextInt();
        
        for (String emp : nameArr) {
            // Check if the employee's age is less than the age limit
            if (ages.get(emp) < ageLimit) {
                // Remove the employee from the HashMap
                ages.remove(emp);
            }
        }
        
        System.out.println(ages);
    }
}
```

### Explanation:

1. **Scanner Input**: The program reads an age limit `N` from the user.
2. **HashMap Initialization**: A `HashMap` stores employee names as keys and their ages as values.
3. **Iterating with `nameArr`**: We use `nameArr`, which contains the keys (names of employees), to iterate through the employees.
4. **Checking Age**: For each employee, their age is retrieved using `ages.get(emp)`. If their age is less than the age limit, the employee is removed using `ages.remove(emp)`.
5. **Output**: Finally, the modified `HashMap` is printed, containing only the employees whose ages are greater than or equal to the limit.

### Sample Input:
```
25
```

### Sample Output:
```
{Robert=32, John=28}
```

This solution effectively filters out employees whose age is less than the input age limit.

### Code to Add and Access HashMap Elements:

```java
HashMap<String, String> m = new HashMap<String, String>();
m.put("A", "First");
m.put("B", "Second");
System.out.println(m.get("B"));
```

#### Explanation:
1. **Declaration**: `HashMap<String, String> m = new HashMap<String, String>();` initializes the `HashMap` with `String` as both the key and value types.
2. **Adding Items**: `m.put("A", "First");` adds the key-value pair `"A"` and `"First"` to the map. Similarly, `m.put("B", "Second");` adds `"B"` and `"Second"`.
3. **Accessing an Item**: `System.out.println(m.get("B"));` retrieves the value associated with the key `"B"` and prints it.

#### Output:
```
Second
```
